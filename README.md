# E. coli sequencing workflow

Coursework notebooks and reports for exploring sequencing reads and assembly results.

## Code guide

`Python_Code/Q1.ipynb` examines FASTQ reads, subsequences, and read-length plots. `Python_Code/Q2.ipynb` records SPAdes assembly and QUAST quality assessment. `Python_Code/Q3.ipynb` examines BWA alignments and IGV views. Open the notebooks in order to follow the workflow; the linked FASTQ, assembly, alignment, and report assets are needed for the relevant cells. The PDFs and screenshots are historical coursework outputs, not a newly executed analysis.
